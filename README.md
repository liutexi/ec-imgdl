# 云湖防盗链图片下载器

一个独立的小工具：把云湖的防盗链图片正常下载到本地。

可以放在自己电脑上用，也可以直接上传到网站空间，通过浏览器随时用。

---

## 为什么需要它

云湖的图片服务器（`chat-img.jwznb.com`、`chat-img3.jwznb.com`）会校验请求来源：

| Referer | 结果 |
|---|---|
| 不带 Referer（浏览器直接打开、右键另存为） | **403 拒绝** |
| `https://chat-go.jwzhd.com/` | 200 正常 |
| `https://chat-web-go.jwzhd.com/` | 200 正常 |
| 其他任意域名 | 403 拒绝 |

白名单只认云湖主域 `*.jwzhd.com`。

浏览器直连图片时，Referer 是你当前网页的地址，通常不在白名单里，所以必然 403。

本工具把这件事挪到服务端：由 PHP 带着合法 Referer 去取图，再转给浏览器。

---

# 一、上传到网站（线上部署）

## 1. 传哪些文件

把这些传到空间的某个目录，比如 `wwwroot/imgdl/`：

```
index.php       ← 主程序，必须有
config.php      ← 配置，必须有
.htaccess       ← Apache 用（Nginx 可忽略）
cache/          ← 目录，必须可写
   └ .htaccess
```

`启动下载器.cmd` 和 `screenshots/` 是本地用的，**不用传**。

> `.htaccess` 是隐藏文件，用 FTP 工具时记得开启"显示隐藏文件"，否则会漏传。

## 2. 访问保护（默认关闭，按需开启）

默认配置**不设任何门槛**：上传完打开网址，直接就是主界面，粘贴链接就能下。

如果这个地址可能被别人看到，建议加一层。`config.php` 里两种方式任选：

**方式一：URL 密钥（推荐，既方便又有保护）**

```php
'access_key' => 'k7f2x9qa',   // 自己随便编一个随机串
```

然后用这条地址访问**一次**：

```
https://你的域名/imgdl/?k=k7f2x9qa
```

浏览器会记住 90 天。之后直接打开 `https://你的域名/imgdl/` 就是主界面——把这条带 `k` 的地址存成书签即可，不用每次输东西；别人没有这个 `k` 就进不来。

程序会自动把地址栏里的 `k` 去掉，不留在浏览历史里。

**方式二：口令**

```php
'password' => '你的口令',
```

进页面要输口令，连错 5 次锁 10 分钟。

> 两个都留空 = 完全开放（默认）。
> 两个都填 = 满足任一即可进入。

## 3. 目录权限

`cache/` 目录必须可写，否则下载全部失败。

- 一般 `755` 就够
- 如果页面顶部提示"cache 目录不可写"，改成 `777` 再试
- 实在不行就手动建一个空目录 `cache`，再给权限

页面上会直接显示这个检查结果，不用去翻日志。

## 4. 访问

```
https://你的域名/imgdl/
```

放在子目录、还是放在根目录，都可以——程序内部全用相对路径，不依赖安装位置。

如果根目录已经有别的 `index.php`，放在子目录就行。

## 5. Nginx 用户

Nginx 不读 `.htaccess`，需要自己在站点配置里加一段，防止缓存被直接访问：

```nginx
location ~ ^/imgdl/cache/ {
    deny all;
}
location ~ ^/imgdl/(config\.php|urls\.txt)$ {
    deny all;
}
```

不加也能用，只是 `cache/` 里的文件理论上能被直接访问到（文件名是哈希，不大会猜到）。

# 二、在本机用

## 双击启动

双击 `启动下载器.cmd`，浏览器自动打开。关掉黑窗口即停止。

## 命令行

```bash
php index.php https://chat-img.jwznb.com/xxxx.jpg

# 从文件读（一行一个，可混杂文字，自动提取链接）
php index.php -f urls.txt
```

下载的图落在 `cache/`，命令行会打印每张的结果和总大小。

---

## 用法

1. 打开网址（如果开了访问保护，先过一下校验）
2. 粘贴图片链接（一行一个，或直接粘整段聊天记录）
3. 点「解析并下载」
4. 单张下载，或勾选后「打包下载 ZIP」

---

## 功能

- **打开即用**：默认没有任何登录步骤，进页面直接干活
- **访问保护（可选）**：需要时才开，URL 密钥或口令两种
- **自动提取链接**：粘贴聊天记录、网页源码、Markdown 都行，自动挑出图片地址并去重
- **并发下载**：默认 6 路（可在 config 调整，虚拟主机建议别超过 6）
- **图片校验**：只接受真正的图片（按文件头判断），错误页会被标为失败而不是存成坏文件
- **单张下载 / ZIP 打包**：ZIP 是程序自己写的，不依赖 PHP 的 zip 扩展
- **导入链接文件**：按钮选本地 txt，纯浏览器读取，不上传服务器
- **单次上限**：默认 200 个链接，防止一次请求跑超时（可在 config 改）
- **深色模式**：跟随系统；`?theme=dark` / `?theme=light` 可强制
- **预填参数**：`?q=<链接>&auto=1` 能把一批地址做成书签，打开即跑

---

## 配置项（config.php）

| 项 | 说明 |
|---|---|
| `password` | 访问口令，留空 = 不校验（默认） |
| `access_key` | URL 密钥，留空 = 不校验（默认） |
| `max_bytes` | 单张图片上限，默认 20MB |
| `conc` | 并发数，默认 6 |
| `max_urls` | 单次最多处理多少个链接，默认 200 |
| `cache_days` | 缓存保留天数，默认 7 |
| `referer` | 抓图用的 Referer，破防盗链的关键，一般不用改 |

---

## 边界与说明

**只抓云湖的域名**（`*.jwznb.com`、`*.jwzhd.com`），其他链接会忽略并计入"已跳过"。

这是故意的：放开任意域名，这个页面就成了可以被别人拿来探测内网的开放代理。

**缓存**在 `cache/`，文件名是链接的哈希。过期文件会在某次请求时顺带清理。想立刻清空就删掉里面的文件（`.htaccess` 留着）。

**访问保护只挡"随手访问"，不是一个账号体系。**

默认状态下，谁拿到地址谁就能用——页脚会有一行淡字提示你现在处于这个状态。

开了 URL 密钥或口令，能挡住不知道密钥的人，但挡不住专门盯着打的人。需要更强保护，可以叠加主机面板自带的目录密码（Basic Auth）。

## 文件结构

```
云湖图片下载器/
├── index.php          主程序（网页 + 命令行，单文件）
├── config.php         配置（口令、并发、上限）
├── .htaccess          Apache 保护规则（Nginx 可忽略）
├── cache/             下载缓存，必须可写
│   └ .htaccess        禁止直接访问
├── screenshots/       界面截图
├── 启动下载器.cmd      本机双击启动（线上不用传）
└── README.md          本文件
```

可选：目录下放一个 `urls.txt`（一行一个链接），页面会多出「载入 urls.txt」按钮，命令行也能 `-f urls.txt` 直接用。

## 环境要求

**PHP 7.4 或更高**，需要 `curl` 和 `json` 扩展（绝大多数空间都有）。

不需要 `zip`、`gd`、`fileinfo`——ZIP 打包和图片识别都是程序自己实现的。

---

## 常见问题

**页面顶部提示"cache 目录不可写"**
把 `cache/` 权限改成 755，不行再试 777。

**上传后整站 500**
说明主机禁用了 `.htaccess` 里的指令。删掉 `.htaccess` 文件即可，功能不受影响（只是少了缓存目录的保护）。

**登录后刷新又要输口令**
服务器 session 不可用。检查 PHP 的 `session.save_path` 是否可写。

**下载很慢或中途失败**
调小 `config.php` 里的 `conc`（比如改成 3），或减少单次链接数量。

**提示"返回的不是图片"**
那个链接可能已经失效，或者返回的是错误页。用浏览器打开原页面确认一下。
